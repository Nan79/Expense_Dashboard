วิธีหา URL และ Token

  1. เปิดชีตแล้วไปที่ Extensions > Apps Script
  2. รันฟังก์ชัน setupToken แล้วคัดลอก API_TOKEN จาก Execution log
  3. Deploy เป็น Web app (Execute as: Me, Who has access: Anyone) แล้วคัดลอก URL ที่ลงท้าย /exec
